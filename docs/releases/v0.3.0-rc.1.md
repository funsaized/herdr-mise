# Herdr Mise v0.3.0-rc.1

## Purpose

This is a prepared release candidate (RC), not a stable or already published release. It adds fixture-backed support for Herdr snapshot protocols 21 and 22, a TUI agent statistics table that preserves workspace identity across scopes, and browser control, focus, and locator improvements. Browser settings and agent panels restore focus predictably; the pane locator is keyboard-accessible and copyable, including when the canvas renderer is unavailable.

## Install

After `v0.3.0-rc.1` is published, download the archive for your platform and its matching `.sha256` sidecar from that GitHub release. Verify the checksum **before** extracting or running the binary (replace `<target>` with one of the targets below):

```sh
shasum -a 256 -c herdr-mise-v0.3.0-rc.1-<target>.tar.gz.sha256 \
  && tar -xzf herdr-mise-v0.3.0-rc.1-<target>.tar.gz \
  && ./herdr-mise
```

On Linux use `sha256sum -c` instead of `shasum -a 256 -c`. Run `./herdr-mise --tui` for the terminal interface. The intended tag is `v0.3.0-rc.1`; archives and sidecars are not available until separate authorized publication. No checksum or public-download result is claimed here.

## Herdr compatibility

The checked-in compatibility authority (`compatibility/herdr.json`) and sanitized fixtures cover this tested matrix:

| Herdr release                | Snapshot protocol |
| ---------------------------- | ----------------- |
| `0.7.5`                      | `17`              |
| `0.8.0`                      | `19`              |
| `0.8.2`                      | `20`              |
| `0.8.2 (development commit)` | `21`              |
| `0.9.0`                      | `22`              |

Protocol 21 is pinned to a development commit, not a general 0.8.2 stable-release claim. Other Herdr releases on supported protocols may connect but are outside this tested matrix. A missing, incompatible, or unsupported local Herdr source shows an explicitly labeled demo feed rather than pretending to be live.

## Limitations

- Herdr Mise is read-only and local: it does not control agents or expose a remote dashboard. The browser server binds only to `127.0.0.1:8686` by default (`HERDR_MISE_PORT` can change the loopback port).
- Release targets are macOS arm64 (`aarch64-apple-darwin`), macOS x86_64 (`x86_64-apple-darwin`), and Linux x86_64 glibc (`x86_64-unknown-linux-gnu`). Linux builds use Ubuntu 24.04 (glibc 2.39 baseline); older glibc, musl, Windows, and Linux ARM are not claimed supported.
- The TUI needs a UTF-8-capable terminal with room for its compact or tiled layout. Manual VoiceOver speech/focus acceptance for this candidate has not been recorded; automated semantic and keyboard checks are not a substitute for listening. No public artifact, signing, or human acceptance is claimed by these notes.
