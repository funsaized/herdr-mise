# Herdr Mise v0.4.0

## Purpose

This candidate adds browser attention and a service recap to the read-only Herdr visualizer. It is not yet a published release.

An open, connected live page shows the global known blocked count in its tab title and a static attention favicon, independent of workspace filtering or background visibility. Desktop notifications are off by default and require explicit opt-in with browser permission. They contain generic counts and escalation stages, not agent identities, workspace paths, or pane locators.

Open **Recap** in the browser or press **R** in the TUI to inspect bounded, renderer-local observations, including observed time blocked. Recap retains 4096 closed observations plus the current roster; its workspace scope is independent of the kitchen filter. Plated counts observed entries into Done, and 86’d counts explicit ended observations, not authoritative task throughput or historical human wait time.

## Install

After publication, download the archive for your supported target and its matching `.sha256` sidecar from the v0.4.0 GitHub release. Until then, use a locally packaged candidate for validation or the published v0.3.0 release for stable installation. Verify the checksum before extraction or launch (replace `<target>` with a supported target):

```sh
shasum -a 256 -c herdr-mise-v0.4.0-<target>.tar.gz.sha256 \
  && tar -xzf herdr-mise-v0.4.0-<target>.tar.gz \
  && ./herdr-mise
```

On Linux, use `sha256sum -c` instead of `shasum -a 256 -c`. Run `./herdr-mise --tui` for the terminal interface. Checksums are generated from the actual archives, not supplied in these candidate notes.

After publication and public verification, upgrade a Herdr-managed installation by rerunning `herdr plugin install funsaized/herdr-mise`. For standalone installations, rerun the pinned installer described in [operations](../operations.md#standalone-installer). Both modes verify the candidate before atomically switching `current`, retain the previous version for rollback, and support idempotent reinstallation. Do not use this checkout's candidate installer against public downloads before publication.

## Herdr compatibility

The unchanged checked-in compatibility matrix and sanitized fixtures cover Herdr 0.7.5 (snapshot protocol 17), 0.8.0 (19), 0.8.2 (20), a 0.8.2 development commit (21), and 0.9.0 (22). Protocol 21 is pinned to a development commit, not a general 0.8.2 stable-release claim. Other releases on supported protocols are outside this tested matrix. Missing or incompatible local sources show a labeled demo feed rather than live data.

## Limitations

- Notifications require an open page, live connectivity, and browser permission. Opening, hiding, reconnecting, or enabling notifications does not replay existing blocked work. OS policy and browser background scheduling may delay or suppress delivery; each opted-in page operates independently without cross-tab deduplication.
- Recap is neither persisted nor backfilled. Reloading the browser or restarting the TUI loses local history; switching demo/live resets it, while reconnecting or changing scope does not. Uncertain connection gaps since the last healthy state observation are excluded. Open durations and waits are provisional and may decrease after delayed failure detection; observed blocked time does not verify its cause.
- Herdr Mise remains read-only and local: it cannot control agents or expose a remote dashboard. The browser server binds only to loopback. Demo remains visibly labeled, and connecting/disconnected pages do not present retained records as current blocked work.
- Release targets remain macOS arm64 (`aarch64-apple-darwin`), macOS x86_64 (`x86_64-apple-darwin`), and Linux x86_64 glibc (`x86_64-unknown-linux-gnu`, Ubuntu 24.04 / glibc 2.39 baseline). Older glibc, musl, Windows, and Linux ARM are not claimed supported.
- The TUI requires a UTF-8-capable terminal with space for its compact or tiled layout. Screen-reader speech listening is not a release gate; automated accessibility and keyboard, focus, and announcement checks remain required.
