# Herdr Mise v0.2.0

## Purpose

Herdr Mise v0.2.0 is the second stable release of the read-only Herdr observability plugin. It ships both browser and native terminal interfaces for monitoring agent activity, source health, and recovery state without mutating Herdr.

This release makes the installer upgrade path a first-class, tested behavior: a v0.1.0 installation upgrades in place to v0.2.0 with the prior version retained for rollback. The native TUI remains part of the product contract, with responsive tiled and compact layouts, truthful working/blocked/idle state rendering, deterministic scene behavior, and clean terminal restoration.

## Install

Download the archive for your platform from the `v0.2.0` GitHub release together with its matching `.sha256` sidecar. Verify the sidecar before extracting:

```sh
shasum -a 256 -c herdr-mise-v0.2.0-<target>.tar.gz.sha256
tar -xzf herdr-mise-v0.2.0-<target>.tar.gz
./herdr-mise
```

Run `./herdr-mise --tui` for the native terminal interface. The browser interface listens only on `127.0.0.1:8686`. To upgrade an existing installation, run the installer or the public-artifact verifier against the new archive in the same install root; the prior version remains available for rollback.

## Herdr compatibility

This release supports Herdr snapshot protocols 17, 19, and 20, including Herdr 0.7.5, 0.8.0, and 0.8.2. Herdr Mise connects read-only to the local Herdr socket, reports source health explicitly, and falls back to demo mode when no compatible source is available.

## Limitations

- The browser service binds to localhost on port `8686` by default;
  `HERDR_MISE_PORT` selects another loopback port.
- Herdr Mise is read-only; it does not start, stop, or control agents.
- Supported release archives are macOS arm64, macOS x86_64, and Linux x86_64.
- The TUI requires a terminal large enough for either its compact or tiled layout and a UTF-8-capable environment.
- VoiceOver speech and focus behavior has automated semantic coverage but was not manually listened to for this release.
- Stable promotion required every non-deferred automated and manual acceptance row to pass against the exact accepted RC1 identity.
