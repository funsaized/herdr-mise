# Herdr Mise v0.3.0

## Purpose

This release adds fixture-backed Herdr snapshot protocol 21 and 22 support, a TUI agent statistics table that preserves workspace identity across scopes, and browser control, focus, and locator improvements. Browser settings and agent panels restore focus; the keyboard-accessible pane locator remains copyable when the canvas renderer is unavailable.

## Install

Once the stable release is published, download the archive for your platform and its matching `.sha256` sidecar from the `v0.3.0` GitHub release. Verify the checksum before extraction or launch (replace `<target>` with a supported target):

```sh
shasum -a 256 -c herdr-mise-v0.3.0-<target>.tar.gz.sha256 \
  && tar -xzf herdr-mise-v0.3.0-<target>.tar.gz \
  && ./herdr-mise
```

On Linux, use `sha256sum -c` instead of `shasum -a 256 -c`. Run `./herdr-mise --tui` for the terminal interface. No stable archive or checksum is claimed before publication.

## Herdr compatibility

The checked-in compatibility matrix and sanitized fixtures cover Herdr 0.7.5 (snapshot protocol 17), 0.8.0 (19), 0.8.2 (20), a 0.8.2 development commit (21), and 0.9.0 (22). Protocol 21 is pinned to a development commit, not a general 0.8.2 stable-release claim. Other releases on supported protocols are outside this tested matrix. Missing or incompatible local sources show a labeled demo feed rather than live data.

## Limitations

- Herdr Mise is read-only and local: it cannot control agents or expose a remote dashboard. Its browser server binds to loopback by default.
- Release targets are macOS arm64, macOS x86_64, and Linux x86_64 glibc (Ubuntu 24.04 / glibc 2.39 baseline). Older glibc, musl, Windows, and Linux ARM are not claimed supported.
- The TUI requires a UTF-8-capable terminal with space for its compact or tiled layout. Screen-reader speech listening is not a release gate; automated accessibility and keyboard, focus, and announcement checks remain required.
