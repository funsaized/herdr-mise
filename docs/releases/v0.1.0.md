# Herdr Mise v0.1.0

## Purpose

Herdr Mise v0.1.0 is the first stable release of the read-only Herdr observability plugin. It ships both browser and native terminal interfaces for monitoring agent activity, source health, and recovery state without mutating Herdr.

The native TUI is part of the v0.1.0 product contract. It provides responsive tiled and compact layouts, truthful working/blocked/idle state rendering, deterministic scene behavior, and clean terminal restoration.

## Install

Download the archive for your platform from the `v0.1.0` GitHub release together with its matching `.sha256` sidecar. Verify the sidecar before extracting:

```sh
shasum -a 256 -c herdr-mise-v0.1.0-<target>.tar.gz.sha256
tar -xzf herdr-mise-v0.1.0-<target>.tar.gz
./herdr-mise
```

Run `./herdr-mise --tui` for the native terminal interface. The browser interface listens only on `127.0.0.1:8686`.

## Herdr compatibility

This release is validated against supported Herdr snapshot protocol 19 and the public RC1 artifact identified by the stable acceptance contract. Herdr Mise connects read-only to the local Herdr socket, reports source health explicitly, and falls back to demo mode when no compatible source is available.

## Limitations

- The browser service binds to localhost and uses fixed TCP port `8686`.
- Herdr Mise is read-only; it does not start, stop, or control agents.
- Supported release archives are macOS arm64, macOS x86_64, and Linux x86_64.
- The TUI requires a terminal large enough for either its compact or tiled layout and a UTF-8-capable environment.
- Stable publication remains blocked until every required automated, manual, and elapsed-time acceptance row passes against the exact accepted RC1 identity.
