# Browser and TUI scene parity

> Every visible browser kitchen-scene treatment, mapped to the shipped TUI
> pane (`server/src/tui/scene/` and the surrounding pieces in
> `server/src/tui/`). Status is exactly **Done** or **Deferred**; the
> notes column carries representation differences. The browser
> implementation (`client/src/scene/`, `client/src/theme/`,
> `client/src/chrome/`) and the shipped TUI source and tests were audited
> directly. This is a current source-backed representation audit, not a pinned
> historical snapshot.
> A deferral that exists because it would only add a redundant signal at this
> resolution is still called out below; no gap is undocumented.
