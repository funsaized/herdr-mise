# TUI scene parity — Phase 2

> Every visible browser kitchen-scene treatment, mapped to the shipped TUI
> pane (`server/src/tui/scene/` and the surrounding pieces in
> `server/src/tui/`). Status is exactly **Done** or **Deferred**; the
> notes column carries representation differences. The browser
> implementation (`client/src/scene/`, `client/src/theme/`,
> `client/src/chrome/`) was audited directly against the integration on
> `33da6d32`. The audit was performed as part of DOCMEDIA-01 and
> corrected against shipped source as part of DOCMEDIA-02.

This document is the checklist the plan commits as deliverable 7 of
Phase 2 (`docs/tui-plugin-plan.md` line 249). The plan's rule: "no
undocumented gaps", so a deferral that exists because it would only
add a redundant signal at this resolution is still called out below.
